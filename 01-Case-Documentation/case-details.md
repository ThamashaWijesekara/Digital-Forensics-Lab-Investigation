# Digital Forensics Investigation

## Case Information

- Case ID: DF-2026-001
- Case Title: Unauthorized File Deletion and Digital Evidence Examination
- Case Type: Simulated Digital Forensic Investigation
- Investigation Date: 2026-11-10

## Incident Description

A simulated company environment contains digital files
that may have been deleted, hidden, or disguised through
file extension manipulation.

The investigation aims to examine the provided digital
evidence and identify relevant forensic artifacts.

## Investigation Objectives

1. Identify existing and deleted files.
2. Examine file metadata.
3. Detect file extension mismatches.
4. Identify actual file types using file signatures.
5. Verify evidence integrity using SHA-256.
6. Reconstruct a timeline of relevant file activities.
7. Prepare a forensic investigation report.

## Tools

- FTK Imager 4.5.0.3
- Autopsy 4.23.1
- Windows PowerShell
- SHA-256
- ExifTool

## Investigation Scope

This investigation uses artificially created evidence
files in a controlled laboratory environment.

No real company data or third-party devices are involved.

## Expected Deliverables

- Forensic disk image
- SHA-256 hash records
- Deleted file analysis
- Metadata analysis
- File signature analysis
- Investigation timeline
- Final forensic report
